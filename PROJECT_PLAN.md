\# College Discovery Platform



A production-oriented college discovery and comparison platform built using Next.js, TypeScript, Prisma, PostgreSQL, and Tailwind CSS.



\## Features



\- College Listing \& Search

\- College Detail Pages

\- Compare Colleges

\- Authentication

\- Saved Colleges

\- Saved Comparisons



\## Tech Stack



\### Frontend

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



\### Backend

\- Next.js API Routes

\- TypeScript



\### Database

\- PostgreSQL

\- Prisma ORM



\### Deployment

\- Vercel

\- Neon PostgreSQL
